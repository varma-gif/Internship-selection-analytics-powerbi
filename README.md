# Internship Selection Analytics Dashboard

## About the Project

I created this project to analyze internship application and selection data using **Microsoft Power BI**.

The main purpose of the dashboard is to turn the raw internship data into simple visual insights. Instead of checking the data row by row in Excel, the dashboard makes it easier to understand application numbers, selections, rejection patterns, candidate performance, and other important details.

This project helped me practice the complete basic data analytics workflow — from preparing the dataset to building an interactive dashboard and presenting the results.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel

## What I Worked On

* Prepared and cleaned the raw dataset
* Checked the data for missing or inconsistent values
* Transformed the data using Power Query
* Created the required calculations and measures using DAX
* Built charts and KPI cards in Power BI
* Added filters/slicers for interactive analysis
* Designed the dashboard to make the results easy to understand

## Dashboard Analysis

The dashboard focuses on areas such as:

* Total internship applications
* Selected and non-selected candidates
* Selection rate
* Department-wise analysis
* Candidate performance
* Internship role-wise analysis
* Comparison of different categories
* Overall selection trends
